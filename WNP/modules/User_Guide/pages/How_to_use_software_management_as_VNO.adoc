= How to use software management as {vno-initials}

== Introduction

This section describes how to use the {app-short-name} SW Management proxy as an {vno-initials}.

When {app-short-name} is installed over Altiplano, the {vno-initials} must execute all the requests through the application proxy.
Instead of using the Altiplano's Software Management URL:
https://{altiplano-host}/nokia-altiplano-ac/

The {vno-initials}s must point to {app-short-name} IBN proxy URL:
https://{altiplano-host}/{wnp-sm-context}/

//Refer to xref:User_Guide:How_to_use_WNP_as_INP.adoc[How to Use {app-short-name} as {inp-initials}] section to know how to define rules globally and per {vno-initials}.

[NOTE]
====
Before using {app-short-name} as an {vno-initials} you must be authenticated as {vno-initials} user.
Refer to xref:User_Guide:How_to_manage_WNP_access.adoc[How to Manage {app-short-name} access] section to know the steps needed.
====

=== Using the REST Proxy

==== Target Solutions

===== Create Target Solution
To create a target solution using the {app-short-name} SW Management proxy you must execute the following step:

.  Send a POST request to the following URL:
link:https://{altiplano-host}/{wnp-sm-context}/rest/software/v1/target-solutions[https://{altiplano-host}/{wnp-sm-context}/rest/software/v1/target-solutions,window=_blank]
+
Body::
The request must contain the following JSON body:
+
[source, json]
----
{
	"name": "{TargetSolutionName}",
	"target-solution-info": "{TargetSolutionInfo}"
}
----
- *name:* The string that identifies the target solution name.
- *target-solution-info:* A serialized JSON string containing the configuration details of the software solution. It specifies the software versions and device models.

[NOTE]
====
The url is the same as the offered by Altiplano Software Management but the difference is that instead of pointing to
nokia-altiplano-ac context the URL points to {app-short-name} proxy context (*{wnp-sm-context}*).
====

For example:: If an {vno-initials} wants to create a target solution, a POST request must be sent to the URL:
https://{ip-host-example}/{wnp-sm-context}/rest/software/v1/target-solutions
+
The following request body must be sent:
+
[source, json]
----
{
    "name": "TS_ontSoftwareR24.01",
    "target-solution-info": "[{\"target-release\":{\"display\":\"R24.01.00\",\"swFileFullPath\":\"R24.01.00\"},\"target-onu-software-mapping\":[{\"index\":1,\"target-release\":{\"display\":\"R24.01.00\",\"swFileFullPath\":\"R24.01.00\"},\"target-vendor-specific-release-1\":{\"display\":\"test-vendor-specific-release-1\",\"swFileFullPath\":\"test-vendor-specific-release-1\"},\"target-vendor-specific-release-2\":{\"display\":\"test-vendor-specific-release-2\",\"swFileFullPath\":\"test-vendor-specific-release-2\"},\"scope-criteria\":[]}],\"target-vendor-specific-release-1\":{\"display\":\"test-vendor-specific-release-1\",\"swFileFullPath\":\"test-vendor-specific-release-1\"},\"target-vendor-specific-release-2\":{\"display\":\"test-vendor-specific-release-2\",\"swFileFullPath\":\"test-vendor-specific-release-2\"}}]"
}
----

[NOTE]
====
The access token of the {vno-initials} user must be sent in the request as a Bearer Authorization HTTP Header.
To retrieve a token, follow the steps in the xref:How_to_manage_WNP_access.adoc#_rest_apis_proxies_and_kafka_brokers[REST APIs, proxies and kafka brokers] section.

===== Duplicate Campaign

To duplicate a campaign using the {app-short-name} SW Management proxy you must execute the following step:

.  Send a POST request to the following URL:
link:https://{altiplano-host}/{wnp-ac-context}/software-management/duplicate-campaign/<CAMPAIGN_NAME>[https://{altiplano-host}/{wnp-ac-context}/software-management/duplicate-campaign/<CAMPAIGN_NAME>,window=_blank]
+
Path Variable::
+
* *CAMPAIGN_NAME*: It is the string that identifies the campaign.
+
Body::
The request must contain the following JSON body:
+
[source, json]
----
{
    "name": "{NewCampaignName}",
    "description": "{CampaignDescription}",
    "start-time": "{CampaignStartTime}",
    "end-time": "{CampaignEndTime}",
    "activities-to-duplicate": [ "{ActivityName1}",  "{ActivityName2}",  "..."]
}
----
- *name:* The string that identifies the campaign name.
- *description (optional):* It is the description of the campaign.
- *start-time:* Defines the beginning of the campaign's execution window. Activities can only be scheduled or triggered after this timestamp. Only the ISO8601 format is supported.
- *end-time:* Defines the expiration of the campaign's execution window. No activities are allowed to start or continue execution beyond this point. Only the ISO8601 format is supported.
- *activities-to-duplicate (optional):* A list of activity IDs from the source campaign to be replicated in the new campaign. If omitted, the new campaign will be created with no activities.

[NOTE]
====
The {app-short-name} proxy introduces a dedicated endpoint under the *{wnp-ac-context}* context. Use the following URL: https://{altiplano-host}/{wnp-ac-context}/software-management +
This endpoint is not offer by Altiplano Software Management.

The following request body must be sent:

    "name": "new duplicated campaign based on UpdateONTsTo24.01.00",
    "description": "duplicated campaign",
    "start-time": "2026-04-01T13:00:00Z",

==== Activities

===== Create Activity

To create an activity using the {app-short-name} SW Management proxy you must execute the following step:

.  Send a POST request to the following URL:
link:https://{altiplano-host}/{wnp-sm-context}/rest/software/v1/campaigns/<CAMPAIGN_NAME>/activities[https://{altiplano-host}/{wnp-sm-context}/rest/software/v1/campaigns/<CAMPAIGN_NAME>/activities,window=_blank]
+
Path Variable::
+
* *CAMPAIGN_NAME*: It is the string that identifies the campaign.
+
Body::
The request must contain the following JSON body:
+
[source, json]
----
{
    "name": "{ActivityName}",
    "operation-timeout": "{ActivityOperationTimeout}",
    "scheduled-start-time": "{ActivityScheduledStartTime}",
    "reachable": "{DeviceReachable}",
    "force-ont-software": "{ForceOntSoftware}",
    "operation": "{OperationType}",
    "max-no-of-error-before-pausing": "{MaxNroOfErrorBeforePausing}",
    "ont-activation-option": "{OntActivationOption}",
    "ont-activation-vendor-specific-release1": "{OntActivationOption}",
    "ont-activation-vendor-specific-release2": "{OntActivationOption}",
    "activity-devices": [
        {
            "fiberName": "{FiberName1}",
            "oltDeviceId": "{OltDeviceId1}",
            "hardware-type": "{hardwareType1}",
            "device": "{device1}"
        },
        {
            "fiberName": "{FiberName2}",
            "oltDeviceId": "{OltDeviceId2}",
            "hardware-type": "{hardwareType2}",
            "device": "{device2}"
        },
        "..."
      ]
}
----
- *name:* The string that identifies the activity name.
- *operation-timeout:* The maximum duration allowed for the activity to complete, expressed in minutes.
- *scheduled-start-time (optional):* Specifies the date and time when the activity is set to begin. If omitted, the activity will trigger immediately after the campaign starts.
- *reachable:* Defines if device must be reachable. It is a boolean value.
- *force-ont-software (optional):* It is a boolean value. Specifies whether the ONT software version should be strictly forced based on the device intent. Its value by default is "false".
- *operation:* Defines the operation type. Possible values are: "software-download", "software-upgrade" and "software-rollback".
- *max-no-of-error-before-pausing:* It number indicates the maximum count of errors before pausing the activity's execution.
- *ont-activation-option:* Possible values are: "delayed-activation" and "immediate-activation".
- *ont-activation-vendor-specific-release1:* Possible values are: "delayed-activation" and "immediate-activation".
- *ont-activation-vendor-specific-release2:* Possible values are: "delayed-activation" and "immediate-activation".

===== Edit Activity

To edit an activity using the {app-short-name} SW Management proxy you must execute the following step:

.  Send a PATCH request to the following URL:
link:https://{altiplano-host}/{wnp-sm-context}/rest/software/v1/campaigns/<CAMPAIGN_NAME>/activities[https://{altiplano-host}/{wnp-sm-context}/rest/software/v1/campaigns/<CAMPAIGN_NAME>/activities,window=_blank]
+
Path Variable::
+
* *CAMPAIGN_NAME*: It is the string that identifies the campaign.
+
Body::
The request must contain the following JSON body:
+
[source, json]
----
{
    "name": "{ActivityName}",
    "operation-timeout": "{ActivityOperationTimeout}",
    "scheduled-start-time": "{ActivityScheduledStartTime}",
    "reachable": "{DeviceReachable}",
    "force-ont-software": "{ForceOntSoftware}",
    "operation": "{OperationType}",
    "max-no-of-error-before-pausing": "{MaxNroOfErrorBeforePausing}",
    "ont-activation-option": "{OntActivationOption}",
    "ont-activation-vendor-specific-release1": "{OntActivationOption}",
    "ont-activation-vendor-specific-release2": "{OntActivationOption}",
    "activity-devices": [
        {
            "fiberName": "{FiberName1}",
            "oltDeviceId": "{OltDeviceId1}",
            "hardware-type": "{hardwareType1}",
            "device": "{device1}"
        },
        {
            "fiberName": "{FiberName2}",
            "oltDeviceId": "{OltDeviceId2}",
            "hardware-type": "{hardwareType2}",
            "device": "{device2}"
        },
        "..."
      ]
}
----
- *name:* The string that identifies the activity name to edit.
- *operation-timeout:* The maximum duration allowed for the activity to complete, expressed in minutes.
- *scheduled-start-time (optional):* Specifies the date and time when the activity is set to begin. If omitted, the activity will trigger immediately after the campaign starts.
- *reachable:* Defines if device must be reachable. It is a boolean value.
- *force-ont-software (optional):* It is a boolean value. Specifies whether the ONT software version should be strictly forced based on the device intent. Its value by default is "false".
- *operation:* Defines the operation type. Possible values are: "software-download", "software-upgrade" and "software-rollback".
- *max-no-of-error-before-pausing:* It number indicates the maximum count of errors before pausing the activity's execution.
- *ont-activation-option:* Possible values are: "delayed-activation" and "immediate-activation".
- *ont-activation-vendor-specific-release1:* Possible values are: "delayed-activation" and "immediate-activation".
- *ont-activation-vendor-specific-release2:* Possible values are: "delayed-activation" and "immediate-activation".
- *activity-devices:* The list of ONTs on which the activity must be executed. If an empty list is provided in a PATCH request, the system will ignore the update for this field and preserve the previously configured devices.

====
The url is the same as the offered by Altiplano Software Management but the difference is that instead of pointing to

----

    "name": "upgradeSoftware",

    "operation-timeout": 180,
